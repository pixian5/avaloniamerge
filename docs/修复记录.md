# 修复记录

## 2026-08-05

- 文件文本比较改为显式检测 UTF-8、UTF-16 和 UTF-32，并保留换行风格及末尾换行状态。
- 文件逐行差异改用 Myers 算法，避免创建 O(N*M) 的二维 LCS 数组。
- 二进制比较保留尺寸先判断、分块流式读取和首个差异早停；读取循环能处理短读。
- 目录差异的父目录状态改为根据变更路径向上标记，避免对所有条目反复扫描。
- GUI 对比任务增加忙碌保护和输入快照，避免重复点击导致结果交叉覆盖。
- 完全一致的非空目录现在会显示成功 toast；删除仅右侧条目前增加确认窗口。
- macOS/Linux 打开路径改用 `ArgumentList`，支持包含空格的路径。
- CLI 严格校验未知参数和路径数量，增加目录比较方法参数，并用退出码 `1` 表示存在差异。
- 保持 Avalonia 11.3.10 的 macOS 渲染稳定性，并显式锁定修复版 `Tmds.DBus.Protocol 0.21.3`，消除已知高危漏洞。
- 增加 `AvaloniaMerge.Tests` 回归测试项目，覆盖换行、UTF-16、目录状态和大文本比较。
- macOS 运行验证要求当前用户会话已解锁；锁屏或显示器休眠时，CoreVideo 可能没有活动显示器，Avalonia Native 会返回 `-6661`。

## 验证

```bash
dotnet restore AvaloniaMerge.sln
dotnet build AvaloniaMerge.sln -c Release --no-restore
dotnet run --project AvaloniaMerge.Tests -c Release --no-build
```
